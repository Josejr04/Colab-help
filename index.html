1. Quiz-day steps, in order

Follow these top to bottom every time. Step 9 is how you hand it in.

  1. Open a notebook and name it simply

    Open the quiz notebook in Colab. If you make a new one, give it a short name with no spaces, such as quiz1.ipynb. You will type this exact name in the export command at the end.

  2. Put the CSV where the notebook can see it

    Upload the CSV with the folder icon on the left side of Colab. It should sit in the content folder. Class tip from the slides: keep the notebook file under the content folder too. If the quiz gives different upload instructions, follow the quiz.

  3. Cell 1: import the four libraries

    Words or labels = categorical (gender, ethnicity, lunch). Numbers you can average = numeric (math_score, alcohol). Dates = time series. Optional check:

    object usually means text, float64 and int64 mean numbers, datetime64[ns] means a real date.

A. Setup and first look

Load a CSV and look at it

Use when: always, first thing after the imports.

df = pd.read_csv('student.csv')
df.head()      # first five rows and all column names
df.dtypes      # type of each column

Read it: head() shows 5 rows by default. dtypes tells you object (text), int64 or float64 (numbers) or datetime64[ns] (dates).

Select columns by position with iloc

Use when: you need a block of columns, such as only the numeric ones before a correlation.

new_df = df.iloc[:, 0:11]    # all rows, columns 0 to 10 (11 is NOT included)
new_df.head()

Remember: iloc[rows, columns]. The colon alone means "all". The end number is excluded, so 0:11 gives 11 columns. In winequality.csv this drops the last column, quality. In student.csv the three score columns are df.iloc[:, 5:8].

B. One category column

Count plot (how many in each label)

Use when: the question asks for counts or frequency of a category. Works for any number of labels.

plt.figure(figsize=(5, 3))
sns.countplot(data=df, x='gender', hue='gender',
              palette={'female':'hotpink', 'male':'skyblue'})
plt.show()

Say it: "There are slightly more girls than boys in this sample. Overall, boys and girls are fairly evenly distributed." (Counts: female 518, male 482.)

Count plot in percent, with long labels

Use when: the question asks for percent, or labels overlap on the x-axis.

plt.figure(figsize=(5, 4))
sns.countplot(data=df, x='parental_education', hue='parental_education',
              stat='percent')
plt.xticks(rotation=40)
plt.show()
# gender as percent
plt.figure(figsize=(5, 3))
sns.countplot(data=df, x='gender', hue='gender',
              palette={'female':'hotpink', 'male':'skyblue'},
              stat="percent")
plt.show()

# counts of every math score (81 different values)
df['math_score'].value_counts()

Read it: stat='percent' changes the y-axis from counts to percent. plt.xticks(rotation=40) tilts the labels. parental_education has 6 labels, so a count plot is the right choice.

Get the labels and counts for a pie chart

Use when: you plan a pie or donut. Pie needs two plain lists: the numbers and the names.

df['gender'].value_counts()                    # table of counts
gender_freq  = df['gender'].value_counts().tolist()           # [518, 482]
gender       = df['gender'].value_counts().index.tolist()     # ['female', 'male']
gender_color = ['hotpink', 'skyblue']
print(gender, gender_freq)

Read it: value_counts() counts each label, biggest first. .tolist() turns the counts into a list. .index.tolist() turns the label names into a list. The names and counts line up in the same order.

Simple pie from two typed lists

Use when: the question gives you the numbers directly instead of a CSV column.

prod = [500, 300]
prod_name = ['iphone', 'ipad']
color = ['lightblue', 'steelblue']

plt.figure(figsize=(4, 4))
plt.pie(prod, labels=prod_name, colors=color, autopct='%1.2f%%')
plt.show()

Read it: same pie code, just with your own lists. Numbers first, names in labels=, colors in colors=.

Pie chart

Use when: part-to-whole, 5 labels or fewer.

plt.figure(figsize=(4, 4))
plt.pie(gender_freq, labels=gender, colors=gender_color, autopct='%1.2f%%')
plt.show()

Read it: autopct='%1.2f%%' prints the percent on each slice with 2 decimals. %1.0f%% gives none, %1.1f%% gives one. Pie takes no data= or x=, only the list of numbers first.

Donut chart

Use when: same as pie, with a hole in the middle. Same 5-label limit.

plt.figure(figsize=(4, 4))
plt.pie(gender_freq, labels=gender, colors=gender_color, autopct='%1.1f%%',
        startangle=90, wedgeprops={"width": 0.5})
plt.show()

Same recipe for another column (exercise 4: test_preparation_course, none 642 and completed 358):

t_value  = df["test_preparation_course"].value_counts().tolist()
t_names  = df['test_preparation_course'].value_counts().index.tolist()
t_colors = ['red', 'teal']

plt.figure(figsize=(3, 3))
plt.pie(t_value, labels=t_names, colors=t_colors, autopct='%1.0f%%',
        wedgeprops={"width": 0.5}, startangle=180)   # donut; drop wedgeprops for a plain pie
plt.show()

Read it: wedgeprops={"width": 0.5} is what cuts the hole (a smaller width means a thinner ring). startangle rotates where the first slice begins.

C. One number column

Histogram

Use when: you need the shape, center and spread of one numeric column.

plt.figure(figsize=(5, 3))
sns.histplot(data=df, x='math_score', color='green')
plt.show()

# variations used in class
sns.histplot(data=df, x='math_score', color='green', fill=False)             # outline only
sns.histplot(data=df, x='math_score', color='green', binwidth=8, alpha=0.5)  # each bar covers 8 points, see-through
sns.histplot(data=df, x='math_score', bins=20, fill=False, kde=True, color='teal')  # exactly 20 bars + curve

Say it: "Math scores range from about 0 to 100. Most students scored between 55 and 80, so scores are concentrated in that range." binwidth = width of each bar. bins = number of bars. Draw each chart in its own plt.figure and plt.show() when you do this on the quiz.

Smooth curve (KDE)

Use when: you want the distribution as a smooth curve with no bar edges.

# histogram plus a smooth curve on top
plt.figure(figsize=(5, 3))
sns.histplot(data=df, x='math_score', color='green', kde=True)
plt.show()

# only the curve, filled
plt.figure(figsize=(5, 3))
sns.kdeplot(data=df, x='math_score', fill=True, color='green')
plt.show()

Read it: KDE = kernel density estimate, a smoother version of the histogram. The taller the curve at a value, the more data near that value.

D. Two number columns

Scatter plot

Use when: both columns are numeric and the question is about a relationship.

# simple
plt.figure(figsize=(5, 3))
sns.scatterplot(data=df, x='reading_score', y='math_score', color='grey')
plt.grid(True)
plt.show()

# split by group with hue
plt.figure(figsize=(5, 3))
sns.scatterplot(data=df, x='reading_score', y='math_score', hue='gender',
                marker='o', s=50, alpha=0.6,
                palette={'female':'#f15bb5', 'male':'blue'})
plt.grid(True)
plt.show()

Say it: "There is a strong positive correlation between reading and math scores." With hue: "At the same reading score, male students tend to have slightly higher math scores than female students." For reading vs writing: "male and female students tend to have similar writing scores." s = dot size, alpha = transparency (0 to 1).

E. Many number columns

Correlation heatmap (full)

Use when: the question asks which numeric variables are related, positively or negatively.

df = pd.read_csv('winequality.csv')
new_df = df.iloc[:, 0:11]          # numeric columns only, no 'quality'
coco = new_df.corr()               # correlation table

plt.figure(figsize=(6, 6))
sns.heatmap(coco, square=True, cmap='PiYG_r', linewidth=0.5, vmin=-1, vmax=1)
plt.xticks(rotation=70)
plt.show()

Read it: each cell is a correlation from -1 to +1. Near +1 = move together, near -1 = move opposite, near 0 = no linear relationship. The diagonal is always 1 (a variable with itself). Wine results from class: fixed acidity and citric acid 0.67, fixed acidity and density 0.67, free and total sulfur dioxide 0.67, fixed acidity and pH -0.68, volatile acidity and citric acid -0.55, density and alcohol -0.50.

Half heatmap with numbers

Use when: you want only one triangle (the other half repeats it) and the values printed.

tri_matrix = np.triu(coco)         # upper-triangle matrix, used as the mask
print(tri_matrix)                  # zeros below the diagonal

plt.figure(figsize=(6, 6))
sns.heatmap(coco, square=True, cmap='PiYG_r', linewidth=0.5, vmin=-1, vmax=1,
            mask=tri_matrix, annot=True, fmt='.1f')
plt.xticks(rotation=70)
plt.show()

Read it: mask= hides cells, annot=True prints the numbers, fmt='.1f' shows one decimal.

Two numbers in more detail (dots, density, regression, contour)

Use when: a scatter plot is too crowded, or you want a trend line.

# dots
plt.figure(figsize=(4, 4))
sns.scatterplot(data=df, x='fixed acidity', y='alcohol', color='skyblue')
plt.show()

# density contours only (both x and y in kdeplot)
plt.figure(figsize=(4, 4))
sns.kdeplot(data=df, x='fixed acidity', y='alcohol', color='blue')
plt.show()

# stacking: draw both in the same figure
plt.figure(figsize=(4, 4))
sns.scatterplot(data=df, x='fixed acidity', y='alcohol', color='skyblue')
sns.kdeplot(data=df, x='fixed acidity', y='alcohol', color='blue')
plt.show()

# scatter + regression line + both histograms
sns.jointplot(data=df, x='fixed acidity', y='alcohol', kind='reg')
plt.show()

# contour plot split by group
plt.figure(figsize=(4, 4))
sns.kdeplot(data=df, y='alcohol', x='sulphates', hue='quality',
            palette='RdPu', bw_adjust=1, levels=5)
plt.show()

Read it: contour rings are like a topographic map: the innermost ring is where the data is most dense. levels = number of rings. bw_adjust = smoothness (bigger = smoother). kind='reg' adds a fitted line.

F. Compare groups (number by category)

Box plot

Use when: compare medians, spread and outliers of a number across categories. x is categorical, y is numeric.

sns.catplot(data=df, x='gender', y='math_score', kind='box',
            hue='gender', palette={'female':'hotpink', 'male':'skyblue'})
plt.show()

Read it: box = Q1 to Q3 (middle 50%), line in the box = median, whiskers reach the last non-outlier point, dots beyond the whiskers = outliers. Whiskers do not always reach the true min or max; the true min and max are the outlier dots. See the diagram in Section 5.

Violin plot

Use when: compare the whole distribution shape (not just the box) across categories.

sns.violinplot(data=df, x='gender', y='math_score', hue='gender',
               palette={'female':'hotpink', 'male':'skyblue'})
plt.show()

Read it: a wider part of the violin means more students at that score.

Point plot (group means)

Use when: compare group averages. The default bars are the 95% confidence interval.

# mean + 95% confidence interval
plt.figure(figsize=(5, 3))
sns.pointplot(data=df, x='gender', y='math_score', linestyle='--')
plt.title('Mean and 95% Confident Interval of Math Score by Gender')
plt.show()

# mean + 95% confidence interval across ethnicity
plt.figure(figsize=(5, 3))
sns.pointplot(data=df, x='ethnicity', y='math_score', linestyle='--')
plt.show()

# whole range (min, max) + mean per group
plt.figure(figsize=(5, 3))
sns.pointplot(data=df, x="ethnicity", y="math_score", errorbar=("pi", 100),
              capsize=.2, color="hotpink", linestyle="none", marker="D",
              mfc='blue', mec='skyblue', markersize=10)
plt.title('Math Score Gap by Ethnicity')
plt.grid()
plt.show()

# separated by a second category
plt.figure(figsize=(5, 3))
sns.pointplot(data=df, x='ethnicity', y='math_score',
              linestyle='--', hue='gender',
              palette={'female':'hotpink', 'male':'skyblue'})
plt.grid()
plt.show()

Read it: the dot is the group mean. errorbar=("pi", 100) stretches the bar to the full data range (min to max). capsize = width of the end caps. linestyle="none" removes the connecting line. marker="D" = diamond. mfc / mec = marker fill / edge color. Class result: mean math score about 68.7 for male and 63.6 for female.

KDE curves by group

Use when: compare distribution shapes across categories, especially when the groups have different sizes.

plt.figure(figsize=(5, 3))
sns.kdeplot(data=df, x='math_score', hue='gender', common_norm=False, fill=True,
            palette={'female':'hotpink', 'male':'skyblue'}, lw=2)
plt.title('Distribution of Math Score by Gender')
plt.show()

Read it: common_norm=False scales each group on its own, so a smaller group is not drawn lower just because it has fewer rows. hue splits the data by a category and gives each group its own color. lw = line width.

G. Made-up data and line plots

Draw a function

Use when: the question gives a formula (y = log(x), y = sin(x), y = 2x + 6) and a number of points.

# 300 points from 1 to 10, then y = log(x)
x = np.linspace(1, 10, 300)
y = np.log(x)

plt.figure(figsize=(5, 3))
plt.gca().set_facecolor('#cbf3f0')           # background color of the plot area
plt.plot(x, y, color='#ff7d00', linestyle='-', linewidth=5)
plt.grid()
plt.show()

# other class examples
x = np.linspace(0, 10)      # default is 50 points
y = np.sin(x)
y = 2 * x + 6               # a straight line

# sin curve drawn with plt.plot
plt.figure(figsize=(5, 3))
plt.plot(x, np.sin(x), color='hotpink', lw=5)
plt.gca().set_facecolor('lightgrey')
plt.grid()
plt.show()

Read it: np.linspace(start, stop, num) gives num evenly spaced numbers and includes both ends. More points = smoother curve. np.linspace(0, 10, 5) is [0, 2.5, 5, 7.5, 10]. Functions like np.log and np.sin work on the whole array at once.

H. Time series and trend line

Workflow from class: text date, then real date, then numeric date, then fit, then plot. Dataset: annual_gold.csv with columns Date, Gold, Platinum (1986 to 2025, one row per year).

Step 1: Fix the date column

df = pd.read_csv('annual_gold.csv')
df.dtypes                                   # Date shows as object (text)

df['Date'] = pd.to_datetime(df['Date'])     # text to real dates
df['Date_ordinal'] = df['Date'].map(pd.Timestamp.toordinal)   # dates to numbers
df.head()
df.dtypes                                   # Date is now datetime64[ns]

Read it: to_datetime converts date-like text into pandas datetime. toordinal turns each date into a number (days since 0001-01-01) so a regression can use it. Check: 1986-12-01 becomes 725341. The raw text 1986-12 is shown as 1986-12-01 after conversion.

Step 2: Plot the series

# gold only
plt.figure(figsize=(12, 5))
sns.lineplot(data=df, x='Date', y='Gold', marker='X',
             markersize=12, color='goldenrod')
plt.grid(axis='y', lw=0.5)
plt.show()

# platinum only

5. Everything for multiple choice

Facts, rules and traps. Skim this before the quiz and keep it open.

The core rule

The data type determines the chart type, and the chart type determines which pattern is easiest to see.

Categorical: counts, proportions, label frequency. Best first view: count plot. Pie or donut only for a few labels.

Numeric: shape, center, spread, outliers. Best first views: histogram, KDE, point plot, box plot.

Multivariate: relationships and comparisons across two or more variables. Use hue to compare distributions by group.

Box plot anatomy and outliers

IQR = Q3 - Q1

Lower limit = Q1 - 1.5 x IQR

Upper limit = Q3 + 1.5 x IQR

Points outside the limits are outliers. Whiskers stop at the last point inside the limits, so they are not always the true min and max. The true min and max are the outliers.

Pie vs count plot

Pie works best with 5 labels or fewer. With more labels, viewers cannot compare angles and areas. Bars share a common baseline, so differences are easier to see.

Donut = pie with a center hole (wedgeprops={"width": .4}).

Class numbers: gender (2 labels): female 518, male 482. test_preparation_course (2): none 642, completed 358. parental_education (6): some college 226, associate's 222, high school 196, some high school 179, bachelor's 118, master's 59.

Histogram vs KDE

Histogram: frequency of numbers in discrete bins. Inspect shape and spread.

KDE: smooths the distribution into a continuous curve. Compare shapes without bin boundaries.

histplot(kde=True) gives both. kdeplot gives only the curve.

Correlation

Range: -1 to +1. +1 = perfect positive, -1 = perfect negative, 0 = no linear relationship.

Heatmap = a visual table of many pairwise correlations. Good for spotting positive, negative or weak linear relationships quickly.

Correlation does not prove causation. A high value means "move together", not "one causes the other".

hue and common_norm=False

hue adds a categorical grouping variable. It works in KDE, box, point and scatter plots.

common_norm=False normalizes each group on its own. Use it when groups have different sample sizes so you compare shapes fairly.

Slicing and linspace traps

df.iloc[:, 0:11] = columns 0 to 10 (end excluded). 11 columns.

np.linspace(0, 10, 5) = [0, 2.5, 5, 7.5, 10]. Third argument is the count, not the step. Both ends are included.

np.linspace(1, 10, 300) = 300 numbers from 1 to 10. Default num is 50.

Time series vocabulary

pd.to_datetime(): text to pandas datetime.

pd.Timestamp.toordinal: datetime to a number so a regression model can use it. 1986-12-01 = 725341, "the 725341st day since 0001-01-01".

sns.lineplot(): line plots, good for time series, can add hue and confidence intervals.

np.polyfit(): computes the relationship between time and the variable (linear or non-linear). np.poly1d(): summarizes it as a trend line you can plot.
